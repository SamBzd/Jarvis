# Workstreams

Créer un fichier par branche active lorsque son état non fusionné doit survivre à la session.

Chaque fichier précise au minimum :

- branche et base ;
- objectif ;
- statut ;
- travaux réalisés ;
- validations ;
- questions et risques ;
- prochaine action.

Un workstream ne doit jamais faire passer un travail non fusionné pour un état disponible sur `main`. Supprimer ou archiver le fichier selon la convention du projet après fusion.
